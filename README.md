NEON ORBIT is a single-file neon arcade game: pilot a ship through a collapsing asteroid field, collect energy cores, chain combos up to x8, blast rocks, grab shield cells and survive rising levels, with start, pause, game-over and restart screens and synthesized sound.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
node serve.ts
```

Then open http://localhost:8080 to play (keyboard arrows/WASD + Space, or mouse/touch).
